REST API Usage

You can easily send LaTeX files or code to this server via HTTP:

1. Get PDF Directly (POST /api/compile/pdf)

Send raw JSON LaTeX content:

curl -X POST http://localhost:3000/api/compile/pdf \
  -H "Content-Type: application/json" \
  -d '{"latex": "\\documentclass{article}\\begin{document}Hello World!\\end{document}"}' \
  --output result.pdf

Or upload a .tex file via multipart/form-data:

curl -X POST http://localhost:3000/api/compile/pdf \
  -F "file=@document.tex" \
  --output result.pdf

2. Get Both PDF & TeX Bundle (POST /api/compile/bundle)

curl -X POST http://localhost:3000/api/compile/bundle \
  -F "file=@document.tex" \
  --output document-bundle.zip

3. Universal Endpoint (POST /api/compile)

Use ?format=pdf, ?format=zip, or ?format=json

curl -X POST "http://localhost:3000/api/compile?format=json" \
  -H "Content-Type: application/json" \
  -d '{"latex": "\\documentclass{article}\\begin{document}Test\\end{document}"}'
